# Block catalog

Working synthetic examples of shared components. Fields are not sent anywhere; external video requires explicit activation.

The catalog covers 11 groups: palette, typography, buttons, badges, forms, cards, navigation, feedback, data, overlays and tokens. Sizes, spacing and radii have visible examples; colors follow the active theme. Loading, progress and skeleton are visual states without network requests.

The two interactive examples are independent. Reset restores every field in its group: name, note, demo email, status, checkbox, radio and switch, and clears validation. Email stays in page memory and does not create a subscription. Simultaneous notifications share a stack; each can be dismissed independently.

Gallery, slider and video are centered in the available column with a maximum width of 860 px. Captions and navigation controls remain available on mobile; the slider supports the keyboard.
